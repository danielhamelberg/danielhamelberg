# Daniel Hamelberg

Cloud, platform and DevOps engineer. Lately also working on applied AI evaluation: testing whether
results hold up on data a system has not seen before.

## Recent work

- [redaction-leftovers](https://github.com/danielhamelberg/redaction-leftovers): checks a PDF for
  content that survives redaction, such as earlier saved revisions and unapplied redaction marks,
  and reports where it is without printing it.
- [graph-native-agent-control-plane](https://github.com/danielhamelberg/graph-native-agent-control-plane):
  a small, typed reference implementation of control-plane primitives for graph-based agent systems.
